# Personal Budget & Expense Tracker

## Project Description

The Personal Budget & Expense Tracker is a simple web-based project designed to help users record and view their personal expenses.

This project is being developed progressively as part of the weekly web development coursework.

## Week 2 Features

This week's version includes:

- A structured HTML expense table
- Five sample expense records
- An expense input form
- A category dropdown
- Five expense categories
- A button for adding expenses
- A budget tracker logo
- An embedded budgeting video
- A collapsible "How to use this tracker" section
- Advanced CSS selectors
- Table row hover effects
- Input focus effects
- Alternating table row colors

## Project Files

### index.html

The `index.html` file contains the structure and content of the Budget Tracker.

It includes:

- Header
- Budget tracker logo
- Expense form
- Expense table
- Sample expense records
- Instructions section
- Embedded YouTube video
- Footer

### style.css

The `style.css` file controls the appearance of the website.

It includes:

- Page layout
- Colors
- Form styling
- Table styling
- Alternating table rows
- Hover effects
- Input focus effects
- Button styling
- Responsive video sizing

## Technologies Used

- HTML5
- CSS3

## Advanced CSS Selectors Used

The project uses several advanced CSS selectors, including:

- Descendant selectors
- `:nth-child()`
- `:first-child`
- `:not()`
- `:focus`
- `:hover`

## Future Development

The Add Expense button will become functional when JavaScript is introduced in a later week.

The project will eventually become a fully functional Personal Budget & Expense Tracker.
